# NextServe — APK releases

이 저장소에는 NextServe Android 앱의 **설치 파일(APK)과 릴리스 노트만** 올라갑니다.
소스 코드는 비공개 저장소에서 관리합니다.

- 최신 버전: [Releases → Latest](https://github.com/Dirtfy/nextserve-releases/releases/latest)
- 앱(v0.2.0 이상)은 실행할 때 이 저장소의 최신 릴리스를 확인하고, 새 버전이 있으면 업데이트 팝업을 띄웁니다.
- 모든 APK는 같은 키로 서명됩니다. 그래서 기존 앱을 지우지 않고 덮어쓰기로 설치되며, 데이터도 유지됩니다.
  인증서 SHA-256: `f5:77:77:d5:c4:5f:6a:0e:71:79:3d:fa:05:0c:93:cb:2c:47:c0:57:02:46:2d:0f:fa:5d:81:fd:e2:e5:7e:51`

---

This repository holds only the signed APKs and release notes for the NextServe
Android app (source is private). The app's in-app updater reads
`releases/latest` from here.
